Politique de confidentialité

Dernière mise à jour : 26 octobre 2026. Ce texte décrit ce que fait l'application Android KWA-WATT, telle que son code public le montre. KWA-WATT est une application indépendante, non affiliée à ENEO / SOCADEL, ni à MTN, ni à Orange.

1. En résumé

  • L'application fonctionne hors ligne. En mode visiteur, vos données restent sur votre téléphone.
  • Elle ne contient aucune publicité et aucun outil de mesure d'audience.
  • La connexion Google est facultative. Elle sert seulement à synchroniser vos données entre appareils.
  • Vous pouvez supprimer votre compte et vos données synchronisées depuis l'écran Profil.

2. Données enregistrées sur votre téléphone

Ce que vous saisissez : compteurs (nom, numéro), relevés de consommation, recharges (date, montant, kWh, référence de transaction), crédits d'urgence, réglages, et les photos que vous ajoutez à votre profil. Ces données sont conservées dans le stockage local de l'application. Le jeton à 20 chiffres d'un SMS de recharge n'est pas enregistré.

Le texte d'un SMS que vous collez, ou la photo que vous prenez pour l'import, est analysé sur le téléphone (lecture OCR embarquée) ; il n'est pas envoyé à un serveur.

3. Connexion Google et synchronisation (facultatives)

Si vous choisissez de vous connecter, l'application utilise Google Sign-In, Firebase Authentication et Firestore (projet Firebase de l'application, région europe-west1). Sont alors copiés dans votre espace privé : votre état d'application (compteurs, relevés, recharges, crédits d'urgence, réglages, informations de profil que vous avez saisies) et les photos de profil. Les règles de la base n'autorisent que votre propre compte à lire ou écrire cet espace. Google traite la connexion selon sa propre politique de confidentialité.

4. Autres échanges réseau

  • Configuration à distance : au démarrage, quand le téléphone est en ligne, l'application lit un document public (nom de l'opérateur, liens utiles, codes) dans Firestore. Cette lecture ne contient pas vos données ; le serveur voit, comme pour toute requête, l'adresse IP du téléphone.
  • Polices de caractères : l'interface demande les polices Inter et JetBrains Mono à Google Fonts quand le téléphone est en ligne. Google peut donc voir l'adresse IP du téléphone à ce moment. Hors ligne, une police du système est utilisée.
  • Liens et codes courts : les boutons de recharge ouvrent le composeur du téléphone ; les liens externes s'ouvrent dans votre navigateur ou votre messagerie. Ces services appliquent leurs propres règles.

5. Notifications

Les alertes et rappels sont des notifications locales programmées par l'application sur votre téléphone. Aucun service de notification distant n'est utilisé.

6. Vos choix

  • Exporter vos données : écran Historique.
  • Supprimer votre compte, vos données synchronisées et vos photos du cloud : écran Profil, « Supprimer mon compte définitivement ». Les données restées sur le téléphone se suppriment en désinstallant l'application.
  • Refuser les notifications : dans les réglages d'Android ou de l'application.

7. Cette page web

Cette page est hébergée par GitHub Pages. Elle n'utilise ni cookie, ni traqueur, ni publicité. GitHub, qui l'héberge, peut conserver des journaux techniques selon sa propre politique. Si JavaScript est actif, la page interroge l'interface publique de GitHub (api.github.com) pour afficher la version, la date et la taille de la dernière version publiée ; ce service voit alors l'adresse IP de votre appareil. Sans JavaScript, la page fonctionne de la même façon, sans ces informations.

8. Enfants, modifications et contact

L'application n'est pas destinée à collecter des informations sur des enfants et ne le fait pas de manière spécifique. En cas de changement important, cette page sera mise à jour avec une nouvelle date. Pour toute question ou demande, ouvrez un échange sur la page de suivi du projet (publique : n'y mettez ni numéro de compteur, ni numéro de téléphone, ni jeton).
